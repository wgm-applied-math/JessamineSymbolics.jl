## Introduction

This package is an interface for using [Jessamine.jl](https://github.com/wgm-applied-math/Jessamine.jl) with [Symbolics.jl](https://github.com/JuliaSymbolics/Symbolics.jl)

*Note:* Jessamine is experimental and under development.
Expect the source code to change in unpredictable ways.
